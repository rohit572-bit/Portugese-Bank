# Portugese-Bank
This project analyzes a Portuguese bank’s marketing campaign data to predict whether a client will subscribe to a term deposit. It involves data preprocessing, exploratory analysis, and machine learning model development to improve campaign effectiveness and customer targeting.
The main goal is to build a predictive machine learning model that helps the bank identify potential customers more effectively and improve marketing strategies. The project involves data preprocessing, exploratory data analysis (EDA), feature engineering, and model development using classification algorithms such as Logistic Regression, Decision Trees, and Random Forest.

Key steps:

Cleaning and transforming client and campaign data

Performing EDA to uncover customer and campaign insights

Selecting key features affecting term deposit subscription

Building and evaluating multiple classification models

Comparing model performance using accuracy, precision, recall, F1-score, and ROC-AUC

Objective:
To support data-driven marketing decisions by predicting customer responses, thereby optimizing resource allocation and increasing campaign success rates.
